
# ProjectPilot

ProjectPilot est une application web personnelle de gestion de projets et de tâches.

### Objectif

M'aider à mieux organiser mes projets personnels, à suivre leur progression et à terminer ce que je commence.

### Stack technique

* Frontend : Next.js, React, TypeScript et Tailwind CSS
* Backend : NestJS
* ORM : Prisma
* Base de données : Neon PostgreSQL

Initialisation du projet.
